# Professional Advanced To-Do List Application

A beautifully designed, feature-rich Task Management application built with semantic HTML5, CSS3, and vanilla JavaScript. This project goes beyond basic functionality, offering status filtering and data persistence with a modern UI.

## Features


- **Inline Task Editing (Double-Click):** Allows users to seamlessly edit any existing task directly within the list by double-clicking on the task text.
- **Interactive Toggle State (Single-Click):** A single click instantly toggles a task between Active and Completed states, accompanied by a clean line-through styling and opacity fade.
- **Advanced Status Filtering:** Easily filters tasks between **All**, **Active**, and **Completed** using dynamic navigation button states.
- **Real-time Task Counter:** Features a dynamic tracker ("X Task left") that automatically recalculates based on remaining active tasks.
- **Robust Input Validation:** Adds dynamic visual states and border transformations if an empty task is submitted.
- **Local Storage Persistence:** Saves tasks, their text content, and their specific completion states directly to `localStorage` so data remains safe after a page refresh.
- **Individual Task Deletion:** Every task includes a dedicated trash icon for instant removal from both the DOM and memory.
- **Premium UI/UX Design:** Pixel-perfect cards, consistent typography, professional cyan/blue color palette, and smooth shadow depths.


## Tech Stack

- **Structure:** HTML5 (Semantic Elements)
- **Styling:** CSS3 (Flexbox, Custom Shadows, Transitions)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, Array Methods like .filter())
- **Storage:** Web Storage API (LocalStorage)

## How to Run Locally

1. Clone or download this repository.
2. Open the `index.html` file in any modern browser, or run it using VS Code's **Live Server** extension.
